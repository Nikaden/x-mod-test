# Game Mod Files Repository

Bu depo, oyun modlarının indirme dosyalarını güvenli ve düzenli şekilde barındırmak amacıyla oluşturulmuştur.

## İçerik

Bu repoda aşağıdaki dosya türleri bulunabilir:

* Mod paketleri (.zip, .rar, .7z)
* Güncellemeler
* Kurulum dosyaları
* Yapılandırma (Config) dosyaları
* Gerekli ek dosyalar ve bağımlılıklar

## Amaç

Bu depo yalnızca dosya dağıtımı için kullanılmaktadır. Mod açıklamaları, ekran görüntüleri, sürüm notları ve kullanıcı yorumları ilgili web sitesi üzerinden yayınlanmaktadır.

## Dosya Yapısı

```
GameName/
├── ModName/
│   ├── v1.0/
│   ├── v1.1/
│   └── latest/
├── AnotherMod/
└── README.md
```

## Sürüm Politikası

* Her güncelleme ayrı klasör altında saklanır.
* Eski sürümler mümkün olduğunca korunur.
* En güncel sürüm `latest` klasörü altında bulunabilir.

## Katkı

Bu repo doğrudan topluluk katkılarına açık değildir. Mod gönderimleri ve güncellemeler yalnızca web sitesi üzerinden yönetilmektedir.

## Lisans ve Telif

Bu depoda yer alan dosyaların telif hakları ilgili geliştiricilerine veya hak sahiplerine aittir. Depo yalnızca dosya barındırma ve dağıtım amacıyla kullanılmaktadır. Telif hakkı ihlali bildirimi alınması durumunda ilgili içerikler en kısa sürede kaldırılacaktır.
